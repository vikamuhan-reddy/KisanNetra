The raw model raises a false pest alert on roughly one healthy leaf in twelve. T=0.80 cuts that 2.75× for 6.6 points of recall. Abstaining is cheap here because the node re-images the same plants next cycle.

What this is not

Stated before a judge has to ask.

  • ✕Not running on Qualcomm hardware. Every figure here is software-only validation on desktop CPU. Dragonwing / QCS6490 is the deployment target and Qualcomm integration is the next phase; no NPU profiling has been performed.
  • ✕INT8 quantization does not work on this architecture. It collapsed to ~22% on the disease model and 34.59% on the pest model under every onnxruntime post-training scheme tried; root cause not yet isolated (MobileNetV3 depthwise / squeeze-excite / HardSwish ranges suspected). Both broken files are named BROKEN on disk. FP32 is what ships.
  • ✕No sensor readings are real. The hardware is designed and modelled, not built. Every value in the sensor panel came from a mock generator.
  • ✕No out-of-distribution test yet. All accuracy figures come from held-out splits of the same source distribution. The harness (ood_eval.py) is written; the field photographs have not been collected. This is our largest remaining validation gap and we would rather say so first.
  • ✕No IP rating is claimed. The enclosure is designed for outdoor environmental protection. Nothing has been sealing-tested.
